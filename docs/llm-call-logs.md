# LLM 调用日志

入口：桌面 App → 设置 → 日志。从更新后开始记录，已有旧请求不会回填。

## 查看方式

- 按调用类型、结果筛选，最新记录在前；每页 40 条，按需加载更早记录。
- 请求按 system / user / assistant 等角色分段。JSON 字符串会解析为可展开字段，文本保留真实换行；长图片数据默认折叠。
- 返回展示模型输出，JSON 输出同样按字段展示。推理内容、完整返回字段可展开。
- 原始数据保留实际请求 JSON、原始响应内容与调用元信息；各页可复制完整内容。
- 时间精确到秒，耗时以秒显示。自动刷新默认关闭，开启后仅日志页可见时每 5 秒刷新摘要。

## 覆盖范围

宿主统一模型客户端记录聊天、主动发言、插件选题/重复判断/研究判断/发言、任务完成通知、记忆提取/整理、检索规划和环境感知。未细分的推理仍显示在“辅助推理”中。

桌面端同时记录表情分析、AI 外观编辑的提示词优化和屏幕识别。外部 Codex/研究工具内部发给其模型的请求不在本应用的传输路径上，不属于此日志的覆盖范围；本应用生成通知话术的调用会记录。

## 记录与性能

- Python 在实际 HTTP 请求处读取已序列化请求体，旁路收集响应，不额外发送模型请求；SDK 的每次重试分别记录。
- 流式响应保留原始 SSE 和拼接文本，取消时保留收到的部分。收到 `[DONE]` 后放弃慢 HTTP 尾部仍视为完成。
- 宿主使用有界异步队列和单写入器，桌面端异步读取响应副本。失败不影响模型输出；写入丢失会在日志页提示。
- 不保存鉴权头；请求地址移除凭据与查询参数。提示词、返回和请求图片保存在本地数据库。
- 单次响应日志最多保留 16 MB，超过时详情明确提示；实际返回给调用方的内容不截断。列表不加载请求/响应大字段，只有选中记录才读取详情。
- 当前保留所有记录，不自动清理历史。

交互参考 [Langfuse 的 observation 类型](https://langfuse.com/docs/observability/features/observation-types)与[列表/详情分离](https://langfuse.com/docs/api-and-data-platform/features/observations-api)，复用本地数据库，不引入额外服务。
